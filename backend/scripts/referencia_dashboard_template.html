        Notas de leitura
        • ajustes_vinculados é sempre 0 nos dados migrados — o CSV antigo não guardava o vínculo de um estorno/ressarcimento com a despesa original, então todo ajuste migrado entra como "solto" (conta como receita extra na leitura de saúde). Isso é esperado, não é bug.
        • Dezembro/2025 é um mês parcial (o CSV começa em 08/12/2025) com receita quase zero — a taxa de poupança desse mês fica com um valor extremo (denominador perto de zero). Também esperado.
        • "Todos os meses" aqui é sempre do primeiro lançamento até — se quiser comparar um "Todos os meses" com fim em outro mês, gere o JSON de novo com --hoje.
        • Compromissos Futuros usa a data real de hoje da sessão que gerou este arquivo, não a data em que você está olhando esta página agora.
